# covid-19 analysis
Power Bi analysis on covid-19 data.
My First Power BI Dashboard: 2020 - The year we all stayed home..

Long ago, the four nations lived together in harmony. Then, everything changed when the Fire Nation (COVID) attacked (okay… March 2020, watched too much of Avatar), the world went from “Let’s open our textbooks to..” to “Mute yourself, we can’t hear the teacher” in a matter of weeks.
And like everyone else, I experienced the pandemic, but this time, I decided to analyze it. 

So here it is: my first ever Power BI dashboard. It’s not perfect (don’t zoom in too hard, please 😪), but it’s the start of a journey, one where messy CSV files become clear, visual stories.


🍀My Process

1. Finding the Data

Got my data from Our World in Data..

Read the GitHub documentation like it was a crime investigation file, as the true crime lover that I am.

2. Cleaning the Data

Null values? They got the “replace or remove” treatment.

3. Building the Measures

Created a Global Fatality Rate (deaths ÷ cases × 100).

4. Designing the Dashboard

Picked a dark theme, because drama belongs in dashboards too.

Used cards for the big, scary numbers.

Line charts for “rise and fall” drama.


🍀The Story in the Data

Fatality Rate: 0.96%, less than 1% of confirmed cases ended in death. Still millions of lives lost.

Cases vs. Deaths: Death peaks usually followed case peaks…

Boosters Helped: Countries that rolled out boosters early saw death rates drop faster.

🍀What I Learned

Data is messy. Really messy. But with patience, Power BI, and lots of hot flavoured water (tea), you can turn it into something that tells a story.
This is dashboard number 1, for me, more to come, more to learn, and hopefully… more humor in the process.
